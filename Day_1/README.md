# JavaScript Foundations

This folder is the base layer of the learning path. Before React makes sense, the student should be comfortable with the language itself.

## Learning order

1. Variables (`01_Variables/`)
2. Data types (`02_Data_Types/`)
3. Operators (`03_Operators/`)
4. Control structures (`04_Control_Structures/`)
5. Functions (`05_Functions/`)
6. Template literals (`06_Template_Literals/`)

## What to focus on

- How values are stored and updated
- How decisions and loops control program flow
- How functions turn repeated logic into reusable units
- How modern ES6 syntax makes code shorter and clearer

## Common mistakes

- Mixing up `let`, `const`, and `var`
- Mutating values when a new copy is needed
- Using template strings without understanding interpolation
- Jumping to async code before understanding functions and promises

## Practice checklist

- Write a small variable example without looking at notes
- Convert a long string concatenation into a template literal
- Rewrite one function using arrow syntax
- Explain the difference between a promise and async await in your own words
