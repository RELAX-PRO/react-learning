# Route Definitions

This folder introduces the route table that connects URLs to screens.

## What to learn

- How to define routes
- How route components are grouped

## Key terms

- Router: the navigation system that reads the URL and decides what to render.
- BrowserRouter: the wrapper that makes routing work with the browser history and address bar.
- Routes: the container that picks one matching route from the list.
- Route: the rule that maps a path like `/patients` to a component.

## Why it matters

- Without a router, React does not know how to switch screens by URL.
- BrowserRouter gives your app normal back/forward navigation in the browser.
- Routes and Route keep the page structure organized and predictable.
