# Event Handling

This folder shows how React listens to user actions and turns them into state changes.

## Learn this first

- onClick
- onChange
- Preventing default browser behavior
- Passing values from events into handlers

## What to understand

- Events are the trigger point for UI updates
- Handler functions should stay small and predictable
- Event values usually feed state updates

## Practice checklist

- Log one click event
- Read one input change
- Prevent one form submit
