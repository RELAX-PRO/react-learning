# Day 14: Meta Frameworks (Next.js Fundamentals) 🚀

Welcome to Day 14! You have graduated from "Pure React" and entered the world of **Meta Frameworks**.

While tools like Create React App and Vite are amazing, they generate Single Page Applications (SPAs) that force the browser to do all the heavy lifting (fetching data, calculating routes, rendering HTML).

Next.js is a full-stack React framework that shifts the heavy lifting to the **Server**, resulting in incredibly fast, SEO-friendly applications.

## The 7 Pillars of Next.js

1. **File System Routing**: No more `react-router-dom`. Your folders define your URLs.
2. **Server Components**: Write React code that runs exclusively on the Node server and securely connects to your database!
3. **Client Components**: Interactive islands of Javascript (using `useState` and `onClick`) dropped into your Server pages.
4. **Server Side Rendering (SSR)**: Generating fresh HTML on every single request for live data.
5. **Static Site Generation (SSG)**: Baking HTML at build-time for absolute maximum speed.
6. **Data Fetching Patterns**: Using `Promise.all` to fetch data in parallel on the server.
7. **Deployment Workflows**: Pushing your Next.js masterpiece to the world via Vercel!

Dive into the numbered folders to master each concept!
