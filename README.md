# React Learning Roadmap

This repository is organized as a learning path, not a random collection of examples. The goal is to move from JavaScript basics to React architecture, then hooks, styling, data fetching, navigation, and global state.

The roadmap is intentionally ordered so each section builds on the previous one. Styling includes both general UI library concepts and the modern shadcn/ui approach where it fits naturally.

## How to read this repo

1. Follow the folders in the exact order shown in [roadmap.js](roadmap.js).
2. Treat each topic folder as a small lesson, not just a code sample.
3. Read the README inside each topic folder first when it exists, then inspect the example files.
4. Use the examples to learn the pattern, then rewrite them yourself to confirm understanding.

## Current roadmap

The roadmap currently includes:

- JavaScript Foundations
- React Core Concepts
- Hooks Fundamentals
- Styling Approaches
- Data Fetching
- Navigation
- Global States
- Form and Validation is reserved for later and is intentionally left unchanged in this pass

If you are following the repo in order, treat the README inside each folder as the lesson guide for that topic and the example files as the practice layer.

## Teaching style

Every topic should explain:

- What the concept is
- Why it matters
- When to use it
- Common mistakes
- A small checklist for practice
