# React Core Concepts

This day explains how React builds user interfaces before hooks and external state tools appear.

## Learning order

1. Functional components
2. Component composition
3. Props passing
4. Prop validation
5. Component lifecycle
6. Virtual DOM
7. Rendering elements
8. State initialization
9. State updates
10. Immutability patterns
11. Lifting state up
12. State batching
13. Functional updates
14. Event handling

## Folder map

- component composition
- functional components
- prop passing
- prop validation
- component lifecycle
- lifting state up
- state batching
- State initialization
- State updates

## What to learn here

- How React organizes UI into components
- How data moves through props and state
- Why immutability is required for reliable updates
- How React re-renders when state changes
- How events trigger UI changes
- How the virtual DOM and rendered elements fit into the update cycle

## What matters most

- Keep components small and composable
- Treat state as data that drives UI, not the UI itself
- Understand that rendering is a result of state and prop changes

## Practice checklist

- Build one screen from smaller components
- Pass one prop across at least two layers
- Update a list without mutating it
- Explain the difference between lifecycle and render
