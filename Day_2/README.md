# JavaScript Foundations: Modern ES6 Features

This day completes the JavaScript base before React starts.

## What this section covers

- Destructuring
- Spread & rest
- Modules
- Classes
- Promises
- Async Await

## What the student should understand

- How to unpack values cleanly
- How to combine and copy arrays and objects safely
- How modules organize code across files
- How classes model reusable behavior
- How promises and async await manage async flow

## Practice checklist

- Rewrite a nested object using destructuring
- Copy an array with spread and explain why it matters
- Export one helper and import it elsewhere
- Convert a promise chain into async await
